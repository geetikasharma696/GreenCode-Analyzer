# GreenCode Analyzer

## Software & Industrial Energy Optimization System

### Project Overview

GreenCode Analyzer is a Python-based application designed to analyze software performance, estimate energy consumption and carbon emissions, and identify opportunities for sustainable optimization.

It also provides industrial energy analysis, process-wise calculations, optimization recommendations, and sustainability simulations.

### Software Analysis Modules

1. Static Code Analysis
2. Performance Benchmarking
3. Energy and Carbon Monitoring
4. Original vs Optimized Code Comparison
5. Green Software Analysis Report

### Industrial Analysis Modules

6. Factory Energy Analysis
7. Process-wise Energy Analysis
8. Industrial Optimization Recommendations
9. Before vs After Energy Simulation
10. Industrial Carbon Reduction Analysis
11. Combined Sustainability Report

### Technologies Used

- Python
- Streamlit
- Pandas
- AST (Abstract Syntax Tree)
- psutil
- CodeCarbon

### Installation

Install the required dependencies using:

`py -m pip install -r requirements.txt`

### How to Run

Run the following command in the project terminal:

`py -m streamlit run app.py`

The application will open in your web browser.

### Limitations

- Energy and carbon values are estimates, not direct meter readings.
- Industrial data may be illustrative.
- Improvement results are simulations, not guaranteed real-world savings.
- Carbon calculations depend on emission factors.
- Industrial recommendations are rule-based.

### Future Scope

- Integration with real-time industrial sensors.
- More accurate energy and carbon monitoring.
- Advanced AI-based optimization recommendations.
- Integration with verified emission-factor databases.
- Support for more industrial processes.

### Conclusion

GreenCode Analyzer combines software performance analysis, energy monitoring, carbon estimation, industrial process analysis, and sustainability simulations in one platform.

The project helps identify opportunities to reduce energy consumption and carbon emissions through better optimization practices.
